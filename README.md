# 🎤 Speech Emotion Recognition

A Machine Learning project that predicts emotions from speech audio using MFCC features and a Random Forest Classifier.

## Features
- Upload audio files
- Extract MFCC audio features using Librosa
- Predict emotions from speech
- Interactive Gradio web interface
- Deployed on Hugging Face Spaces

## Tech Stack
- Python
- NumPy
- Scikit-learn
- Librosa
- Gradio
- Hugging Face Spaces

## Installation

```bash
pip install -r requirements.txt
python app.py
